# 界面设计与核对

面向内部制作人员，以批量操作和清晰的处理状态为主。采用白色内容区、浅灰左侧导航、橙色主操作与少量绿色完成状态。设计参考为 `workspace-concept.png`，实现后用真实浏览器截图逐项对照。

| 项目 | 实现与核对 |
|---|---|
| 导航与页面层次 | 桌面固定 214 px 导航；工作台、模板库、任务、检查、账号、管理为独立页面。标题、说明、主操作层级与参考一致。 |
| 批量操作顺序 | 头像上传区在上，订单表和批量操作在中，选择数量与提交操作在下；步骤线提示上传、选模板、生成保存。 |
| 订单行 | 头像与可编辑名称、模板缩略图及编号、打印规格、状态在同一行；空状态和待提交草稿使用真实数据。 |
| 视觉语言 | 橙色 `#f16b3b`、深灰 `#292b30`、细边框 `#e8e9ec`，6–9 px 控件圆角；文字采用系统中文字体，不请求外部字体服务。 |
| 状态表达 | 服务器完成、本机部分保存、全部保存和写入失败分别表达；水印预览和透明打印文件分别展示。 |
| 桌面留白 | 页面横向内边距 48 px，主标题 26 px，订单行高 100 px；保留参考中宽阔的上传区和表格空间。 |
| 小屏幕 | 720 px 以下导航折叠，订单行分两行，模板与结果网格减少列数；390 px 宽度核对无页面横向溢出。 |
| 可操作性 | 键盘焦点、对话框焦点锁定及 Escape 关闭；表单错误、禁用态、待处理提示与草稿持久化提示。 |

有意差异：参考图中的虚构照片、人员和订单未放入正式数据。浏览器验收截图使用独立临时账号和人工构造的测试插画；测试调整过的 50 mm／600 RPM 等数值不代表正式默认配置。正式默认值仍为 85 mm／5 RPM／2 个在途请求。

截图文件包括工作台空状态、带草稿工作台、管理员设置、单张结果对照和手机工作台。设计参考用于整体风格与布局核对；功能验证见 `../verification.md`。
