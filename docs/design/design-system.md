# 界面设计与核对

后台面向内部制作人员，要能批量操作，处理状态要一眼看清；客户选图页面向手机用户，贴纸图片是主角。两者共用一套**温暖可爱**的视觉语言：奶油色底、陶土色主操作、珊瑚粉点缀、圆润的卡片和胶囊标签、暖色柔和阴影。

所有颜色、圆角、阴影和动效都定义在 [`frontend/src/styles/tokens.css`](../../frontend/src/styles/tokens.css)。新增样式只使用这些变量，不要再写十六进制颜色。唯一的例外是水印预览（`.watermark-preview`）：它模拟真实输出的水印，要保留原来的灰色和描边。

## 设计变量

| 类别 | 变量 | 用途 |
|---|---|---|
| 背景 | `--bg` `#fbf6ef`、`--surface` `#fffdfa`、`--surface-raised` `#fff`、`--sunken`、`--sidebar` | 页面底色、卡片/弹窗、输入框与按钮、凹陷区域（缩略图底、表头）、侧栏 |
| 线条 | `--line`、`--line-soft`、`--line-strong`、`--field`、`--field-strong` | 卡片边框、列表分隔、次要按钮边框、输入框边框、搜索框边框（需要更醒目） |
| 文字 | `--ink` `#3a2b25`、`--ink-2`、`--muted`、`--faint` | 正文、次级正文、说明文字；`--faint` 只用于装饰，不承载信息 |
| 品牌 | `--brand` `#b0512f`（陶土色）、`--brand-strong`、`--brand-soft`、`--brand-tint`、`--brand-line` | 主按钮、链接悬停、选中态文字、选中卡片底色和边框 |
| 点缀 | `--coral` `#ef8a7a`、`--coral-soft`、`--coral-ink` | 进度条渐变、分类标签、头像底色、空状态图标；珊瑚粉本身不用作文字色 |
| 状态 | `--ok*`、`--warn*`、`--danger*`、`--info*` | 已完成、处理中、失败/错误、暂停；每种都有配套的浅色底 |
| 圆角 | `--r-xs` 6、`--r-sm` 8、`--r-md` 10、`--r-lg` 14、`--r-xl` 20、`--r-pill` | 复选框、图标按钮、按钮与输入框、卡片、弹窗与提交栏、标签与分段控件 |
| 阴影 | `--shadow-xs` 至 `--shadow-lg`、`--shadow-brand`、`--ring` | 卡片静止、悬停抬起、弹窗、主按钮、输入框焦点环 |

对比度已按 WCAG 2.1 AA 核对：`--ink`、`--ink-2`、`--muted` 在 `--bg`、`--surface`、`--sidebar`、`--sunken`、`--hover` 上都在 4.5:1 以上；陶土色主按钮上的白字约 5.1:1；每种状态色在自己的浅色底上都达到 4.5:1。修改色值后要重新计算对比度。

## 组件约定

| 组件 | 实现 |
|---|---|
| 导航 | 桌面端侧栏固定 214 px（1180 px 以下 185 px）。当前页显示为白色浮起的小卡片，文字和图标用陶土色。720 px 以下侧栏折叠为抽屉。 |
| 按钮 | 主按钮用陶土色底加轻微内高光。次要按钮白底带细边，悬停时变成浅陶土色。危险按钮用 `--danger`。禁用时去掉阴影。 |
| 标签页与分段控件 | 胶囊形容器，选中项为白色浮起的胶囊。宽度按内容收缩，放不下时横向滚动。 |
| 状态 | `.status` 为胶囊标签，完成、处理中、失败分别用绿色、琥珀色、红色的浅底。订单列表的状态用陶土色浅底。 |
| 提示 | `.notice-banner` 用浅陶土色，`.error-banner` 用红色浅底，两者不混用。Toast 为白色浮层，成功图标绿色，失败图标红色。 |
| 卡片 | 订单行、图库卡片、统计卡、店铺卡统一用 `--r-lg` 圆角和 `--shadow-xs`，悬停时加深阴影。选中的卡片用陶土色边框、描边环和浅陶土色底。 |
| 弹窗 | `--r-xl` 圆角，暖色半透明遮罩加模糊，进入时有轻微上浮动画。保留焦点锁定和 Esc 关闭。 |
| 客户选图 | 顶部“已选 x/y”为深陶土色胶囊，滚动时固定在页面上方（手机居中）。页面顶栏不吸顶，以免遮住它。进度条用陶土到珊瑚的渐变。 |
| 空状态 | 珊瑚浅底的圆形图标，外加一圈浅陶土色光环。 |
| 动效 | 只做 150–220 ms 的颜色、阴影和轻微位移过渡。`prefers-reduced-motion` 下全部关闭。 |

## 核对方式

- 类名、ARIA 标签和按钮文案都是 E2E 测试的定位依据，只改视觉时不要更改。
- 对照截图：[后台工作台](theme-workspace.png)、[客户选图（手机）](theme-guest-mobile.png)、[登录页](theme-login.png)。截图使用隔离测试数据和合成头像，不包含真实订单。
- 布局改动需要检查桌面 1440 px 和手机 390 px 两种宽度，390 px 下不能出现横向溢出。
- `admin-settings.png`、`result-review.png`、`workspace-*.png` 是最初版本的布局参考，仅作历史记录，不代表当前界面。
