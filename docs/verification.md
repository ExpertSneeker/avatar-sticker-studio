## 功能覆盖

1. **批量订单与归属**：浏览器创建管理员、导入 12 张模板、输入套装元数据、同时上传两个头像、批量选模板和参数、保存草稿并刷新恢复、提交 24 张任务。后端另测两套反向选择顺序与账号隔离。
2. **单张重跑**：一套完成后重跑一张，累计生成请求由 12 变为 13，旧结果保留到新结果成功。重新排版和更新水印不发起额外生图。后处理失败可从保存的原始结果恢复，无需再次生图。
3. **限速与暂停**：持久化开始时间、全站在途数、并行 worker 争抢、暂停／继续、429 退避和未知结果分类均有回归测试。真实 API 请求固定为模板、头像顺序以及 1K／low／透明 PNG 参数。
4. **断点恢复**：上传分块偏移与重复提交校验；服务中断的在途结果标记待确认；浏览器刷新恢复草稿和目录句柄；缺失下载重新补齐。
5. **本机文件**：浏览器端到端测试使用真实 FileSystemDirectoryHandle 与 IndexedDB，目录选择器替换为隔离的 OPFS 目录。验证实际写入、刷新恢复、补齐缺失页、排版页数减少后清理旧页，以及保留无关文本文件。单元测试补充真实创建空文件的行为、磁盘失败、版本变化、外部文件改动和校验失败。
6. **打印输出**：透明内容裁边、等比缩放、半透明边缘不重复乘 alpha、单套独立分页、A4 2480×3508 和 300 DPI 元数据、85 mm 长边换算均验证。图片不因凑页数缩小。
7. **水印**：完整套装 4×3、256 px 单元、多套纵向接排、白底、45°／25% 水印；实际中文字体检测、不同中文水印产生不同图像、长水印不截断均有测试。
8. **版本隔离**：模板替换和排序创建新版本，旧订单快照保持原样；结果清单记录文件版本、大小和 SHA256。写入意图在文件写入前持久化，完整核对新版文件后才清理旧页。

浏览器额外覆盖：模板编辑弹窗连续输入不丢失焦点、单张序号从 1 开始、管理员密钥输入不显示原文、邀请码生成、手机导航和 390 px 宽度无横向溢出；同页退出登录中止上传，多标签页换账号使旧页面失效，后端拒绝预期账号不一致的请求。最终浏览器流程无页面异常或控制台错误。
