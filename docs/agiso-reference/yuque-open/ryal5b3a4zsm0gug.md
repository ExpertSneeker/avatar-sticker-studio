# 推送权限获取流程

来源：https://www.yuque.com/agiso/open/ryal5b3a4zsm0gug（2026-10-08 抓取的渲染文本，图片未保存）

第一步：开发者申请阿奇索授权

当开发者的应用属于电商业务时，接收推送时需要联系阿奇索在线客服授权需要的权限类型



第二步：开发者获取商家授权

●
开发者找客服授权完推送权限后，给商家提供其AppId

●
商家授权操作入口：自动发货后台--开放平台--授权管理。商家勾选相应要授权的权限。授权后会生成一个Token，将Token复制给开发者（相当于告诉Agiso，允许这个AppId通过Agiso开放平台获取或操作这个店铺的订单数据）
