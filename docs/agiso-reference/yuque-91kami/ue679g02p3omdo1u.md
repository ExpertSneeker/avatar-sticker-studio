这个功能是什么？

对已入库卡密设置成本价

什么时候需要用到它？

录入卡密时没有设置成本，后续补充设置以实现成本和利润的自动统计

静态成本和动态成本差异

1，静态成本

成本单价是固定的，假如静态成本设置为5元，则不管该卡种内的卡密数量如何变动，成本都是5元；

设置静态成本后，后续添加卡券时不再要求设置价格

静态成本后,添加卡券时不再填成本

2，动态成本

成本单价是变动的。

假如该卡种第一批次入库时10个卡密，总价50元，则此时成本单价为5元；

如果下一批次入库是时10个卡密，总价为60元，则此时动态成本为110÷20=5.5元。

每一批次添加卡密，都有要求填写价格。成本单价将自动更改。
