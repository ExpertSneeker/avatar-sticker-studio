场景2，仅允许部分功能

【例如仅授予子账号提卡的权限，其余功能均无法使用】

1）确认需要的权限

提卡需要的操作过程为：卡券库---查询/找到对应卡种---点击"管理卡券"进入卡种里提卡

因此需要“卡券库”相应的“卡种查询”与“提卡”权限



2）分配相应权限

卡券---卡券库----勾选如下2个权限后保存。也可根据实际需要同时勾选多个权限。

●
卡种--查询

●
卡密管理--提卡
