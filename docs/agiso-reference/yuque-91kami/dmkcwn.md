# 如何共享给不同的店铺/不同的平台

来源：https://www.yuque.com/agiso/91kami/dmkcwn（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

91仓库作为一个总仓，可以共享卡密到同一个平台下不同的店铺或者不同的平台（比如：淘宝、拼多多、闲鱼、京东等）

什么时候需要用到它？

同个平台不同店铺或不同平台的店铺想要共享卡券管理时

设置方法：

步骤一：授权91账号

注册91账号：mai.91kami.com  打开这个链接进来点击“免费注册”注册一个属于自己的91账号，再把卡密都添加到这个账号下；

不同的的店铺或者不同的平台要授权给同一个91账号就可以共享同一个91账号下所有的卡券
