# 如何配置采购方案

来源：https://www.yuque.com/agiso/91kami/eugkeh8o2oufqzkr（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

同个商品，多家货源有供货。自动根据价格最优进行采购，也可以按排序，或当前面货源方采购失败，就自动切换到下一个备用货源

什么时候用到它？

1、拥有多家货源时，想节省采购成本又想当采购商缺货或其他问题导致订单没有采购成功时，可以有其他货源方促成交易。提高订单交易成功率

2、几家货源提供同一个商品时。想优先自动按采购价最低的采购

采购方案采购规则如下：

●
优先采购"排序"数字大的商品（例如：3>2>0）

●
同排序的货源，则默认优先采购供货“价格最低”的

●
当某个货源采购失败，就自动进行下一家货源的采购

●
1个货源方案里最多添加3家货源

●
建议添加的自有货源都配置商品回调接口，以实现货源价格变动的自动推送

●
同一货源方案里不能存在不同类型的商品
