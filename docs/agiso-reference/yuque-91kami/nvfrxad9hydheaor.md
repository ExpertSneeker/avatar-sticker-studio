# 什么是卡种类型

来源：https://www.yuque.com/agiso/91kami/nvfrxad9hydheaor（2026-10-08 抓取的渲染文本，图片未保存）

卡种类型是什么？

按卡券内容的特点，将卡券内容按不同的类型分别存到各自的卡种

卡种类型能干什么？

卡种类型分为：可重复，不可重复，图片，无限循环，套卡 5种类型

【禁止重复卡号】：一般指你的卡密，一个卡密只卖一次，不重复卖给其他人。这种卡在建卡种的时候就需要选择这个卡种哦（如：电话卡充值，京东等购物卡，电影票等。。。）



【允许重复卡号】：指一个卡可以重复卖给多个用户使用。(如：允许循环使用的卡密等)



【套卡】：一般是指一个卡密是由多个卡组成，或者长度非常的长。（如：游戏礼包卡等）套卡也是不可重复的



【无限循环使用卡密】：这种一般是没库存的，所有买家购买后发的都是一样的或者几个不一样的循环发送（比如：想跨店共享附言内容，几个共享链接想轮流发送给不同的买家。）
