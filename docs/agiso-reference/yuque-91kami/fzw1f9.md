# 应用授权

来源：https://www.yuque.com/agiso/91kami/fzw1f9（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

91卡券接口可通过接口提卡，加卡等

什么时候需要用到它？

当你需要通过接口对91卡券里的卡券做提卡，加卡的动作时

设置方法：

步骤一：成为开发者

先到新平台注册【注册网址：http://open.agiso.com/#/user/register】

注册后登录开放平台，填写资质认证成为开发者

【资质认证网址：http://open.agiso.com/#/my/account/attestInfoView】

如果您已经是开放平台的开发者，请忽略此步

开放平台需要充值才可以调用接口





步骤二：创建应用

在开放平台创建应用，如果已有应用，请忽略这步



步骤三：开通权限

联系在线客服提供appid 开通对应权限


步骤四：91卡券用户授权

想让哪一个开发者，调你的91卡券的提卡跟入库的权限需要授权应用
