来源：https://www.yuque.com/agiso/91kami/srrowrmeh14ogn68（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

实现登录一个电商平台自动发货后台，自由切换到同平台的其它店铺。需要这些店铺绑定到同一个91账号

什么时候需要用到它？

当你在某个平台有多个店铺，希望快速切换其它店铺自动发货后台，可使用该功能快速登录

设置方法：

步骤一：店铺绑定91账号

进入对应平台自动发货后台--91卡券仓库--卡券管理--立即绑定；

绑定成功后勾选“允许绑定的相同91卡券账号的其它店铺直接切换登录本店自动发货”
