# 角色管理

来源：https://www.yuque.com/agiso/91kami/rqccb6（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

创建不同岗位角色，并批量授权给员工子账号进行管理

什么时候需要用到它？

需要用到91卡券子账号管理系统，希望同岗位角色批量授权时

设置方法：

首先需要已创建91子账号，如何创建：https://www.yuque.com/agiso/91kami/uneppz
