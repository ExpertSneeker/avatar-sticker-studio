# 如何发送二维码或者条形码

来源：https://www.yuque.com/agiso/91kami/wt38hb（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

可将文字卡券自动转换成二维码或者条形码发送给买家

什么时候需要用到它？

如果你的卡券是文字，但需要展示给买家的是二维码或者条形码比较方便买家使用的时候

一般针对卡券是文本或者链接形式的，想展示给买家看的时候展示为二维码或者条形码
