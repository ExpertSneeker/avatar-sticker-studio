这个功能是什么？

步骤一：店铺绑定91账号

授权成功后在91卡券里--管理平台店铺--添加--选择相应平台--登录后即可添加;
添加后，管理平台店铺里看到所有已添加店铺

每个添加成功的店铺均需要购买阿奇索自动发货服务,才可止是自动反

步骤二：多平台多店铺登录后台

1，允许91卡券仓库免密登录到绑定的店铺

勾选"允许绑定91卡券账号直接登录本店铺"，可实现一个91账号免密登录到所有已绑定的店铺



勾选后找到你要登录的店铺--点登录就可以直接进入对应的店铺的自动发货后台【不需要再填写账号密码】





2，允许绑定到同一个91账号的同平台店铺之间快速切换

勾选"允许绑定的相同91卡券账号的其它店铺直接切换登录本店自动发货"，则同平台不同店铺直接可直接切换。
