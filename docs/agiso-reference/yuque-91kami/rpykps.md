来源：https://www.yuque.com/agiso/91kami/rpykps（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

通过自建站可以自己创建一个自己的销售网站

什么时候需要用到它？

当你想有自己的一个店铺，不属于哪一个电商平台，可自行推广，没有收款账期

设置方法：

配置之前如果91自建商城还没有申请开店的需要先申请一下，具体教程请点击查看

你首先要自己有一台windows Server的服务器，还有一个备案好的域名。服务器需要清楚明白怎么登录进去
