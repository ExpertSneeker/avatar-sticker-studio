# 内容模板

来源：https://www.yuque.com/agiso/91kami/lrtx5r29v12igpip（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

 让订单发送内容统一样式，可以方便设置及编辑  

什么时候需要用到它？

 当你有一些商品发的部分内容是一样的就可以使用模板，比如注意事项或者推广自己

【适用于除淘宝外的所有平台，包括全平台发货设置均支持】
