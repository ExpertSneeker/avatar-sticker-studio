这个功能是什么？

将卡种有序排列

什么是时候需要用到它？

如果卡种非常的多，需要排序归类时，这个功能就非常有用哦

设置方法：

步骤一：设置排序的数值

进入91卡券仓库---卡种---点击卡种排序号---点击排序号旁边蓝色标识的笔---手动修改排序数值，将相似的卡种数值填写接近---这样同类卡种就可以排在一起---点击排序号旁边的√
