二、短信

全平台(包括淘宝)，只要使用短信发货方式，除了订购自动发货外，还需要另外购买短信包，以保障短信发送

三、奇豆

使用API接口采购，即直充或采购订单调用接口时，需要消耗奇豆

通常1个订单调用1次接口，消耗5个奇豆，调用失败再手动发起等特殊情况，才会再次调用。

【调用撤单接口，则为10个奇豆/次】
