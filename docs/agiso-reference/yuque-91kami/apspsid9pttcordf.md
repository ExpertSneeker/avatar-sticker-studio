# 库存不足预警通知

来源：https://www.yuque.com/agiso/91kami/apspsid9pttcordf（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

当库存到你设置的库存预警数时会发微信提醒你

什么时候需要用到它？

当你的库存到达一定数量时需要提醒你，防止库存无卡券导致无法发货

设置方法：

步骤一：设置库存预警值

进入91卡券仓库---找到要设置库存预警的卡种---修改卡种---输入库存预警 数值（库存预警数值可按自己的需求设置）---保存
