# 如何手动提卡

来源：https://www.yuque.com/agiso/91kami/yatfyk（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

手动把卡密提取出来

什么时候需要用到它？

当你需要系统外手动发卡密给买家

设置方法：

如下图操作（手动提卡后卡密会相应出库到已售里)








订单编号会默认有一个，如果需要按买家的订单来查询提出的卡密可以填写买家真实的订单号

数量跟买家昵称都要填写

勾选生成网址点确定提卡会显示一条连接，打开可以显示所有的卡密，如果不勾选生成提取链接，点确定后可以手动复制提卡出来的卡密





如果找不到之前提取出来的链接，可以到卡券提取链接里查询
