# 如何使用接口方案

来源：https://www.yuque.com/agiso/91kami/ffttagdd3o2v8rht（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

直充的商品，一个商品可以同时选择多个充值平台充值

什么时候需要用到它？

当你的商品直充时，需要同时选择不同的第三方供应商做充值，就可以用这个功能

例如：有一个商品定价60元，买家付款后会帮他自动充值一张10元及一张50元的充值卡

你可以设置选择充值的是不同的供应商，如10元充值选择A充值供应商，50元充值选择B充值供应商



注意：接口方案只支持直充接口，卡券采购接口不支持这样的方式
