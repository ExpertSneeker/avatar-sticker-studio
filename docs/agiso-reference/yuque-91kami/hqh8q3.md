# 什么时候需要用到91卡券

来源：https://www.yuque.com/agiso/91kami/hqh8q3（2026-10-08 抓取的渲染文本，图片未保存）

什么时候需要用到它？

当你想要数据共享或者设置共享时，需要用到91卡券

用到的场景说明：



场景一：预存款及短信共享

当你的单量会经常超过每日基础单量时，预存款可自动补单量。预存款支持多店共享使用的；



一个91账号下充值的短信套餐，可以多家店铺一起共享使用；

无需多店铺反复充值，节约时间成本，不用担心某一家店铺短信用不完浪费。

前往查看：如何购买短信充值



场景二：店铺异常通知



商品发货助手异常，单量不足时有微信公众号提醒；

当你需要多店铺自动发货服务到期提醒；

卡券不足时提醒。

前往查看：如何关注公众号



场景三：多店共享卡券库存

当你的商品需要事先存储卡券库存，多平台多店铺共用同一个卡券仓库进行管理时



前往查看：共享卡券教程



场景四：多店铺后台切换设置

当你有多家店铺都绑定了同一个91卡券账号时。如何快捷的切换店铺设置自动发货商品



前往查看：如何多店铺切换



场景五：可实现接口共享

当你的店铺需要接入第三方直充平台，或者需要走卡券采购接口时

用91卡券，多店铺接口可以统一化管理



前往查看：如何实现直充接口对接

场景六：商品全平台通用设置共享

 1.一家店铺里有多个商品发货设置一样
2.不同店铺的多个宝贝里某个sku设置是一样的  
3.sku经常会被删除或者经常需要修改的
4.多平台，多宝贝，发送内容一样的 
5.目前除了，虾皮、微信小店、微店外，其他平台都可以用
