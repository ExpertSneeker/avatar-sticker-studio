这个功能是什么？

安全密码主要用于保护重要的信息，如登录后第一次查看卡券、发货记录等，将需要验证安全密码

什么时候需要用到它？

当你操作卡券管理、发货记录等时，不想要输入安全密码验证后才可以操作时可以取消

设置方法：

进入mai.91kami.com 后台，鼠标移到右上角账号下拉选择账号设置--安全设置--安全密码点修改进去
