# 小程序管理自动发货

来源：https://www.yuque.com/agiso/91kami/pma4w0q9uuseldyr（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

手机登录微信小程序进行自动发货设置和管理

什么时候需要用到它？

闲鱼、京东、微店、有赞、得物、视频号、微信小店、虾皮、微盟等在小程序里设置完就可以实现24小时自动发货，不需要电脑挂机；

拼多多：小程序可以管理发货设置，但都还需要电脑下载拼多多发货助手挂机；

小红书：小程序就能实现24小时短信自动发货。但聊天窗发货还需要电脑下载小红书发货助手挂机；

抖店：   小程序就能实现24小时短信自动发货。但聊天窗发货还需要电脑下载抖店发货助手挂机；

快手：   小程序就能实现24小时短信自动发货。但聊天窗发货还需要电脑下载快手发货助手挂机

淘宝：手机千牛上进行设置（不支持微信小程序）

设置方法：

步骤一：绑定微信小程序

首先确保店铺已绑定91卡券，并勾选"允许绑定的91卡券账号直接登录本店铺"

3,勾选启用该功几是为(简款)食用着己灯房该风险,并已同意由自用着自行承相该风险,向奇索不永扫任句责
开启该地项后,绑定的91卡券账号可以在91卡券仓库后台的[渠][管理平台店铺]列表中直接点击登录按机进行登录
,该选项存在定风险,包括但不限于:如果其他店铺发生账密泄漏被盗,将会导致本店铺自动发货也技其他人登录.
,开启该选项后,机定的相同91卡券号的其他店登录自动发货后,无需用户名密码,可以直接切焕登录本店自动发货,
