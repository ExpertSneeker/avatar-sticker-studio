# 如何导出卡券

来源：https://www.yuque.com/agiso/91kami/zt0ulv（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

可将卡券导出为CSV或者文本格式备份

什么时候需要用到它？

需要把卡种里的卡券信息更换到其他卡种或不需要这个卡种时，按下面设置将卡种里的卡券信息导出

设置方法：

步骤一：输入条件

进入91卡券仓库---卡券库---找到要导出的卡种---管理卡券---输入要筛选的条件

可以预先输入要导出的条件（默认显示所有未出库的卡券）
