回收删除的卡种

什么时候需要用到它？

删除的卡种将在系统中保留14天，14天内可以恢复卡种。系统会在每天0点，开始清理14天前删除的卡种。

设置方法：

步骤一：恢复已删除卡种

91卡券仓库---卡券---回收站---选择需要恢复的卡种---恢复
