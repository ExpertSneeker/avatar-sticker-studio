充值后可对第三方接口做订单推送充值，及卡券采购

什么时候需要用到它？

当你有在91卡券平台对接第三方直充平台或者卡券采购平台时

计费说明：直充直采商品，需要调用接口时才需要奇豆，按5奇豆/次，一般一个订单调用一次；

                个别调用失败后，再次手动发货，会增加5奇豆/次的费用；轮询是免费的。
