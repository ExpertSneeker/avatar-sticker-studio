# 发卡方案

来源：https://www.yuque.com/agiso/91kami/yn44hc（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

可按买家购买的数量发对应设置好的卡种

什么时候需要用到它？

当你的商品发货卡密形式比较复杂时可以用到

如：数量拍1时要发多种不同类型的卡

       不同的购买数量发的卡密类型不一样

       买家地区不同，发的卡密类型不同

       按买家留言内容去区分要发哪一种类型的卡密

设置方法：

举例说明：

拍数量1发两个A卡种，拍数量2就发一个B卡种的话

这种就是按数量不同，发不同的卡种。
