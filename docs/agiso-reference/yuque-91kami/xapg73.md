# 商品全平台通用设置

来源：https://www.yuque.com/agiso/91kami/xapg73（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

通过商品外部编码（商家编码）关联， 一份发货设置支持多平台共同使用。适用于有相同商品在多平台或多店铺售卖的商家，省去重复设置的麻烦。

什么时候需要用到它？

1.一家店铺里有多个宝贝设置内容一致  

2.不同店铺的多个宝贝的某个sku设置是一样的  

3.sku经常会被删除或者经常需要修改的

4.多平台，多宝贝，发送内容一样的 

5.一个店铺关了，再开其他店铺也无需重新设置

目前除了虾皮，微信小店，微店外，其他平台都可以用

【91卡券仓库地址：https://mai.91kami.com/建议收藏，以便下次进入】

设置方法：

步骤一：启用全平台发货设置

首先不同店铺需要都绑定到同一个91账号，然后确保开启“使用91卡券全平台发货设置”

【如果用淘宝店铺账号又开通了闲鱼店铺，请勿开启该功能避免资损】

（当启用上述选项，并且对应店铺自动发货后台的 商品设置 未添加时，91全平台发货设置才会生效。因此自动发货后台--商品设置里就不能添加这个商品）

1,开信该选项后,锦定的91卡券账号可以在91卡券仓库后台的[渠道],[管理平台店铺]列表中直接点击登录按扭进行登录
,开启后,未设置自动发货的商品,将自动根据商品编码从91卡券中尝试装取发货设置
3,勾选启用该功能贝认定为(商家)使用者已知浇该风险,并已同意由使用者自行承担该风险,阿奇索不承担任何责任,
,该选顶存在岩风险,包括但不限于:如果其也店铺发生账密泄漏过波盗,将会导致本店辅自动发货也技其他人登录,
,开启该选项后,绑定的相同91卡券账号的其他店登录自动发货后,无需用户名密码,可以直接初换登录本店自动发货,
允许绑定的91卡券账号直接登录本店铺效果滨示
允许绑定的相同91卡券账号的其他店直接切换登录本店自动发货效果演示
