这个功能是什么？

添加并启用充值账号黑名单

什么时候用到它？

使用标准系统、通用接口进行直充/采购时，需要对某些账号限制充值/采购

设置方法：

步骤1：添加黑名单

进入91卡券仓库--货源--充值账号管理--黑名单--添加--可批量添加充值账号--确定
