# 多平台店铺登录后台教程

来源：https://www.yuque.com/agiso/91kami/nxmmmsqarshtn1vs（2026-10-08 抓取的渲染文本，图片未保存）

这个功能是什么？

实现通过登录一个91账号可以登录各平台的自动发货后台

什么时候需要用到它？

当你有多个电商平台店铺，不想记那么多账号和密码时，可使用该功能快速登录

设置方法：

步骤一：店铺绑定91账号

进入对应店铺自动发货后台--91卡券仓库--卡券管理--立即绑定；

绑定成功后勾选"允许绑定的91卡券账号直接登录本店铺"





开启该选项后,绑定的91卡券状号可以在91卡券卡券仓库后台的[渠道]-(管理平台店铺]表中直接点击登录按钮进行登录
,该洗项存在定风险,包括活但不限于:如果其他店机发生账密泄漏或波盗,将会导致本店铺自动发货也被其他人登求.
1,开启该选项后,绑定的相同91卡券账号的其也店登录自动发货后,无需用户名密码,可以直接切换登录本店自动发货,
3,勾选启用该功能则认定为(商家)使用者已知给该风险,并已同意由使用者自行承担该风险,阿奇索不承担任包责任,
1,开启后,未设置自动发货的商品,将自动根据商品编码从91卡券中尝试获取发货设置
允许绑定的相同91卡券账号的其他店直接切换登录本店自动发货效果演示

步骤二：多平台店铺登录后台  

在91卡券里---渠道---管理平台店铺-添加-选择相应平台-登录后即可添加





添加后，即可在91卡券--管理平台店铺里看到；

找到你要登录的店铺--点登录就可以直接进入对应的店铺的自动发货后台【不需要再填写账号密码】
